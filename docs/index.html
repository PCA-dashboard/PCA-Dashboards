      下載這份資料，照著做自己的

      這個 Dashboard 讀的就是下面這個「統一 Zip」。下載後解開來看，就知道自己的資料要長成什麼樣子。

      ↓ 格式說明文件

      Zip 裡面長這樣

      manifest.json              ← 資料集資訊、視圖清單、分組配色
views/<view_id>/scores.csv  ← 每列一物種：species_id, PC1, PC2, …
views/<view_id>/variance.csv← 每個 PC 解釋的變異比例
taxa/taxa.csv              ← species_id, display_label, 分組欄, 其他資訊欄
tree/tree.nwk              ←（可選）Newick 樹，tip 標籤＝species_id

      關鍵：species_id 是 join key，scores／taxa／樹三邊必須一致。所有統計（PCA/GPA）都在匯出端算好，瀏覽器只負責呈現。
