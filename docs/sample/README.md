# 範例資料（給建立精靈試跑用）

17 個假物種、3 個科、2 種棲地的迷你資料集。用來實際走一遍建立精靈的流程，
不必先準備自己的資料。

| 檔案 | 在精靈裡對應的欄位 |
|------|-------------------|
| `scores.csv` | ② PCA 視圖 → 分數 CSV |
| `variance.csv` | ② PCA 視圖 → variance（可選） |
| `taxa.csv` | ③ 物種／分類資料 → 分類 CSV |
| `tree.nwk` | ④ 親緣樹（可選） |

上傳後按「建立預覽」，右側應該出現 **17 個點、3 群圖例、一棵樹**。
